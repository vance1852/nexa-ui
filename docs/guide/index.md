# Nexa UI

一个基于 Vue 3 + TypeScript + UnoCSS 的现代化组件库，采用原子化设计理念，提供轻量、高性能的 UI 组件。

## 特性

- 🚀 **Vue 3 Composition API**: 完全使用 Vue 3 组合式 API 开发
- 🎨 **UnoCSS 原子化 CSS**: 极致的开发体验和构建性能
- 📦 **Tree Shaking 支持**: 按需引入，只打包你需要的组件
- 🔑 **TypeScript 原生支持**: 完整的类型定义，开发体验更佳
- ✅ **完善的测试覆盖**: 使用 Vitest 进行单元测试
- 🎯 **无障碍支持**: 遵循 WAI-ARIA 规范，提供良好的可访问性

## 设计理念

Nexa UI 遵循以下设计原则：

1. **简洁优先**: 组件 API 设计简洁直观，易于使用
2. **一致性**: 统一的设计语言和交互模式
3. **可定制**: 支持深度主题定制，满足不同业务需求
4. **高性能**: 最小化的运行时开销，流畅的用户体验
5. **可访问性**: 内置无障碍支持，让产品更具包容性
