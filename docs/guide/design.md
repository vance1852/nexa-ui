# 设计规范

Nexa UI 遵循一套统一的设计规范，确保组件在视觉和交互上的一致性。

## 色彩系统

### 主色

- **Primary**: #3b82f6 (蓝色) - 主要按钮、链接、高亮
- **Secondary**: #6b7280 (灰色) - 次要文本、边框

### 语义色

- **Success**: #10b981 (绿色) - 成功状态
- **Warning**: #f59e0b (橙色) - 警告状态
- **Error**: #ef4444 (红色) - 错误状态
- **Info**: #3b82f6 (蓝色) - 信息提示

### 中性色

- **Surface 50**: #f9fafb
- **Surface 100**: #f3f4f6
- **Surface 200**: #e5e7eb
- **Surface 300**: #d1d5db
- **Surface 400**: #9ca3af
- **Surface 500**: #6b7280
- **Surface 600**: #4b5563
- **Surface 700**: #374151
- **Surface 800**: #1f2937
- **Surface 900**: #111827

## 间距系统

使用 4px 基数的间距系统：

| 名称 | 值   | 用途               |
|------|------|--------------------|
| xs   | 4px  | 极小间距           |
| sm   | 8px  | 小间距             |
| md   | 16px | 中等间距（默认）   |
| lg   | 24px | 大间距             |
| xl   | 32px | 超大间距           |

## 圆角系统

| 名称 | 值   | 用途               |
|------|------|--------------------|
| sm   | 4px  | 小组件圆角         |
| md   | 8px  | 中等圆角（默认）   |
| lg   | 12px | 大圆角             |
| xl   | 16px | 卡片、弹窗圆角     |
| full | 9999px | 圆形组件         |

## 字体系统

### 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
```

### 字体大小

| 名称 | 大小   | 行高   | 用途           |
|------|--------|--------|----------------|
| xs   | 12px   | 16px   | 辅助文本       |
| sm   | 14px   | 20px   | 正文（默认）   |
| base | 16px   | 24px   | 正文大         |
| lg   | 18px   | 28px   | 小标题         |
| xl   | 20px   | 28px   | 标题           |
| 2xl  | 24px   | 32px   | 大标题         |
| 3xl  | 30px   | 36px   | 超大标题       |

## 阴影系统

| 名称 | 值                                  | 用途               |
|------|-------------------------------------|--------------------|
| sm   | 0 1px 2px 0 rgb(0 0 0 / 0.05)       | 小组件阴影         |
| md   | 0 4px 6px -1px rgb(0 0 0 / 0.1)     | 卡片阴影（默认）   |
| lg   | 0 10px 15px -3px rgb(0 0 0 / 0.1)   | 弹窗阴影           |
| xl   | 0 20px 25px -5px rgb(0 0 0 / 0.1)   | 大弹窗阴影         |

## 动画系统

- 过渡时长: 150ms
- 缓动函数: cubic-bezier(0.4, 0, 0.2, 1)

```css
transition: all 150ms cubic-bezier(0.4, 0, 0.2, 1);
```
